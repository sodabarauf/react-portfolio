# Reat-Portfolio 📟

## Overview 🎬

This is react portfolio showcasing various projects and skills in web development. 

- Responsive design for optimal viewing on different devices.
- Interactive UI components built with React.
- Dynamic project showcase with filtering options.
- Contact form with email integration.
- Smooth scrolling and navigation.
- Integration with GitHub API to display latest projects.
- SEO optimized for better search engine ranking.
- Deployed on Vercel for fast and reliable hosting.

## DEMO 📺
[Deployment][(https://react-portfolio-5h616y3yi-sodabaraufs-projects.vercel.app/)]
###

## Installation and Setup 🔌

   ```bash
   clone the repo by (git clone git@github.com:sodabarauf/react-portfolio.git)
   change directory by (cd react-portfolio)
   install dependencies by (npm install)
   run server by npm start
   ```
